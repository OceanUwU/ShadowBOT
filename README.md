# ShadowBOT
ShadowBOT is a Discord bot that assists with playing Blood on the Clocktower using voice channels

[Add the bot to your server here](https://discord.com/api/oauth2/authorize?client_id=952917064035741706&permissions=326905572416&scope=bot)

## What can you do with it?
- Shadow players or storytellers, automatically moving to any voice channel they move to
- Quickly modify your server nickname to signify you're spectating, playing, storytelling, co-storytelling, travelling, etc.
- Create timers to display to players how much time is left for private chats
- Store and retrieve a link to a digital grimoire for an ongoing game, lest it get lost in a busy text channel
- Quickly create a poll for which script to play
- Join a waitlist to get pinged when a new game starts
- Display an infobox for a specific game role in chat 
- Get info on curated custom scripts
- etc
